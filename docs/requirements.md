# Chording MVP 要件定義

## 対象

- OS: Windows 11
- ホスト: Cubase
- 形式: VST3エフェクト
- 入力: VST3ノートイベント
- 音声処理: 解析しない。入力音声はそのまま出力する

## コード認識

- major、minor、dim、aug、power chord
- sus2、sus4
- 6、m6、7、maj7、m7、mMaj7、dim7、m7b5
- add9、9、maj9、m9、11、13
- b5、#5、b9、#9、#11、b13
- オンコードと転回形
- 曖昧な構成音に対する主候補と別解
- シャープ／フラット表記切り替え

演奏タイミングのずれを吸収するため、ノート構成が140ms安定してから履歴へ追加する。
ノートを離す途中だけに現れるコードは進行として記録しない。

## キー

- メジャーキーとマイナーキーに対応
- 履歴からの自動推定
- ユーザーによる手動固定

## 次コード提案

候補を最大6件表示し、機能和声、前後関係、共通音、スタイル、印象から順位付けする。

### スタイル

- ベーシック: ジャンル固有の偏りを抑え、機能和声と自然な声部移動を優先
- ポップス: 循環しやすく親しみやすい進行を優先
- ロック: 主要三和音と、許可時にはbIII、bVI、bVIIを優先
- ジャズ: 7th、ツーファイブ、テンションを含む候補を優先

### 印象

- 指定なし
- 明るい
- 切ない
- 緊張
- 意外性

印象はスタイルを置き換えず、候補順位への追加補正として扱う。

### 表示

- コード名
- 安定、展開、緊張、滑らか、意外性などの役割
- 選択した候補の構成音
- ダイアトニックのみ／借用和音を含む、の切り替え

## 履歴と保存

- 最大64コードを保持
- Undo、全消去、テキストコピー
- 設定と履歴をCubaseプロジェクトのプラグイン状態へ保存

## MVP対象外

- 音声からのコード解析
- 候補コードの試聴
- MIDIノートの生成またはDAWへの書き出し
- 教師データやクラウドAIによる提案
- メジャー／マイナー以外のモード
